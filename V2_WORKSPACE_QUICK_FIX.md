# V2 Workspace Sidebar Quick Fix

This patch changes only the full-screen drawing/workspace presentation.

- Opening a non-compact Workspace temporarily collapses the left Study OS sidebar.
- The app content offset is removed while the workspace is open.
- Mobile bottom navigation is hidden while drawing.
- Closing the workspace restores the navigation automatically.
- No database, Supabase, note, flashcard, schedule, or study logic changed.
