# Study OS V2

## Added without removing V1 features

- Legacy cue-card whitespace preservation.
- Structured rich cue-card fronts/backs with paragraph, heading, code, equation, callout and drawing blocks.
- Existing plain-text cards continue to render and can be upgraded through Edit.
- Editable vector Workspace with Pointer Events for mouse/touch/stylus, pressure-aware points, pen, eraser, text, colors, width, undo/redo, clear, zoom, multiple pages and blank/dot/graph/lined backgrounds.
- Drawings can attach to lecture notes and cue cards and reopen for editing.
- New top-level General section for personal events, study blocks, appointments, work and day-to-day deadlines.
- Personal events merge into Dashboard Today and Upcoming views without being mixed into academic database tables.
- Additive Supabase V2 migration with owner-only RLS.
- Sharper experimental engineering visual system inspired by high-contrast computer/editorial design without copying supplied branding or assets.
- Course art accepts PNG first and JPG fallback.
